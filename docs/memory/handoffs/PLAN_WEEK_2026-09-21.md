## H1 — SSH console, user-run (root needed), then a session verifies

On the host, in a terminal (one block):

```bash
sudo apt-get install -y openssh-server && sudo systemctl enable --now ssh && sudo sed -i 's/^#\?PermitRootLogin.*/PermitRootLogin no/' /etc/ssh/sshd_config && sudo systemctl restart ssh && systemctl is-active ssh && ss -ltn | grep ':22 '
```

On the PC, joined to the Opal's wifi, in PowerShell (creates a key if there is none, then installs it on the host — answer the host password once):

```powershell
if (!(Test-Path "$env:USERPROFILE\.ssh\id_ed25519.pub")) { ssh-keygen -t ed25519 -N '""' -f "$env:USERPROFILE\.ssh\id_ed25519" }
type "$env:USERPROFILE\.ssh\id_ed25519.pub" | ssh <user>@<host-lan-address> "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"
ssh <user>@<host-lan-address> "echo key-login-ok"
```

Then, back on the host, key-only:

```bash
sudo sed -i 's/^#\?PasswordAuthentication.*/PasswordAuthentication no/; s/^#\?KbdInteractiveAuthentication.*/KbdInteractiveAuthentication no/' /etc/ssh/sshd_config && sudo systemctl restart ssh && sudo sshd -T | grep -E '^(passwordauthentication|permitrootlogin|kbdinteractiveauthentication)'
```

Session task afterwards (no root): confirm `sshd -T` shows password auth off and root login off, record in `TOOLS.md` that the host console is SSH from the PC on the Opal wifi (no addresses), and that `tmux` + `claude --remote-control` is started from that SSH session from now on.
