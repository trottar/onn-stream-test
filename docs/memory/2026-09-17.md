## D-127 durable incorrect-guide implementation

D-127 is implemented as a bounded Android + Linux TV-state change.

Key decisions:
- guide rejection is separate from Hide/playback health;
- TV user-state moves to v2 with v1 migration support;
- rejected guide provenance is stored as a stable source fingerprint;
- marked guide data is retained but not presented as trusted;
- marked channels become eligible for background recheck only after 24 hours;
- background recheck never clears intent;
- explicit Retry/Accept/Clear controls trust restoration.

Runtime validation remains required before acceptance.

### Delivery-process corrections recorded

Three D-127 delivery errors occurred before runtime validation:

1. The first delivery response supplied Windows PowerShell and
   `L:\Projects\onn-stream-test` commands even though the authoritative host
   is Linux and the active worktree is
   `/home/privyhub/Projects/onn-stream-test`. Those commands failed in Bash
   before the installer ran.
2. A follow-up described D-127-only GUI actions such as `Retry Guide` before
   D-127 had been installed. The current D-126 GUI could not contain those
   controls, so that runtime instruction was invalid.
3. The revision-04 installer treated marker presence as immediate idempotent
   success. It could print `INSTALLED SUCCESSFULLY` without revalidating exact
   generated bytes or running the real Gradle build gate. Marker presence is not
   proof of a valid installed patch.

Durable rules:
- executable user-facing commands must be derived from the active host/shell and
  authoritative worktree, not copied from historical platform examples;
- never ask the user to test patch-only UI before installer/build and APK
  installation have actually completed;
- keep delivery stages explicit: patch install/build -> commit/push -> APK
  install -> required companion restart -> runtime action -> probe/evidence;
- an idempotent installer path must validate exact deterministic output and rerun
  all required validation/build gates; marker presence may select that path but
  may never short-circuit it.
