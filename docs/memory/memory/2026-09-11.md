## B4.6 v1 packaging defect

The first physical-cleanup installer was rejected before modification because
B4.6 v1 hashed literal `\\0` / `\\n` byte sequences while B4.5 used real
NUL/newline canonical separators.

Authoritative project files were not modified.

B4.6 v2 corrects the canonicalization and adds a direct equivalence regression
against the B4.5 implementation.

## B4.6 v2 packaging defect

B4.6 v2 reached the discovery gate and falsely classified the nine
B4.5-authorized RetroArch Moonlight-name collisions as unexpected targets.

The cause was over-escaped literal-dot regexes in the v2 manifest helper.
The installer failed before modification.

B4.6 v3 copies B4.5 discovery semantics exactly and adds direct discovery
equivalence fixtures plus an exact non-target preservation allowlist.
