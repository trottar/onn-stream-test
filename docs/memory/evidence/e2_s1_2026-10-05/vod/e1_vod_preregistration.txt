THE ROW
  E1-VOD   the fixed file movies/Edge Of Tomorrow.mp4 played on the onn through the companion's own route.
           Preflight as E1, plus: the file present and its mount read-only.
           Launch: force-stop the app, wake, MainActivity; tap VOD >, MOVIES >, Edge Of Tomorrow; NOW PLAYING shows
           the title; tap RESTART (0:00); read the progress (p0, t0); tap the preview (fullscreen confirmed).
           Warm-up 60 s. Window 300 s. At the window's end: BACK; read the progress (p1, t1).
           Teardown: RESTART, STOP (POST /stop), no NOW PLAYING left; flags absent; idle.
           Main process: range_server.
  Run twice, back to back, 120-s idle gaps, unit restarted before each run (as every E1 run). Nothing tuned between.
