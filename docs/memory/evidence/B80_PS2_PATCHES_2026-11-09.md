## What was built (`b80.diff`)

- **Host, `companion/ps2_patches.py`:** the ids from PCSX2's logs (the latest launch wins), cached on the hub by game

- **The plugin:** `details.ps2_patches = {"available": […], "on": […]}` only for a PS2 title with an offer (no serial
  or CRC sent); the action `ps2-patches?id=…&ws=0|1&ni=0|1&fps60=0|1`.
- **The onn (`streaming/Ps2Patches.kt`, `MainActivity.kt`):** Extras gains **"Patches…"** when the details offer
  one; it opens a tick list ("Widescreen", "No interlacing", "60 fps"; the current state ticked); **Save** posts the
  toggles and the status line says *"Saved — used the next time this game starts"*. The Extras list is built from one
