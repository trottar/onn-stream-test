## What was built (`tools/h7_endscreen.py`, +484 / −18 lines; version 2 unchanged)

- **When:** every end class in the labels is a place row `end_r<d1..dn>` (the Place row read left to right, port 1
  first; a permutation of 1..n, n 2-4) → **spec version 3**. Anything else — T88's `end_P1` / `end_P2` — learns version
  2 by today's code (`learn_arrays` byte for byte as HEAD's). Mixed labels or a row that is not a permutation: refused.
- **The screens:** `start` and `end` (every place row merged), **each its own mask** (B102's steady pixels of that
  class, minus the pixels half or more of a foreign class's pictures rank within 0.1 of — the window's bands, a frame two
  screens share), its reference, its threshold halfway to the nearest foreign picture. A read: the median rank distance
  to each screen; the class is the screen under its threshold; none → `other`; a searched alignment only if the moved
  picture is as close as the screen's own pictures were.
- **The row, learnt (no boxes):** on the results pictures' ranks at 320 × 240 against the end screen's mask (B104's
  tone-independent measure, at twice the tool's 160 × 120 — a digit there is ~10 × 15), the matches' mean pictures;
  for every spacing and cell size, **the per-pixel ratio of between-place to within-place variance** when every place's
  values come from whichever columns showed it, box-averaged → the row. On T89: **spacing 40 of 320** (120 of the
  960-wide window), origin (61, 133), cell 12 × 8 padded to 20 × 16; ratio 71 against ≤ 2.5 anywhere else, the same in
  every fold. The glyph mask: the padded cell's pixels with a ratio > 1 (163); each column's cell refined ±3 px.
- **A place:** one reference per place, **pooled over every column that showed it**; a column's distance to a place =
  the mean |rank − reference| over the glyph mask, the least over ±1 px; read under the place's threshold and with the
  margin. **A place never shown in a column is read there with the reference learnt in the others, at that column's
  own learnt position** (the row's spacing + the column's refined offset). A place shown in no column cannot be learnt:
  refused ("place q is never shown: the pictures need a match where someone is q-th").
- **A read (version 3):** `{"screen", "class": "end" | "start" | "other" | "unknown", "places": [p1..pn] | null,
  "distances", "margin", "place_distances", "place_margins", "ports"}` — **any column unread, or two columns with the
  same place → `unknown`, `places` null**; `ports` keeps each column's own read. **`Ended`**: K agreeing reads of the
  whole row (the class and the places); version 3 says `end` with the places. `score_places`, `replay` with places,
  `thresholds` for version 3; `load_spec` / `check_spec` take versions 2 and 3 (version 1 refused as before).

## Are these five matches enough for the sitting?

**Yes.** Every place of every held-out match was read right, eight of them in columns that never showed them; the two
pairs these pictures never show (1P 2nd, 3P 4th) are read the same way, through the place's pooled reference at the
column's learnt position. The limits, stated: a pointer or a character standing on a digit for the whole results screen
would leave that column unread → the row `unknown` → no end → after 30 s of an unknown screen the hub gives the mini
game up (a draw) — never a wrong credit; the darkest tone pair can turn one picture's row to `unknown` (the next reads
carry on). **If more certainty is wanted, the smallest further capture is one match with the Place row 2 1 4 3** (1P
2nd, 3P 4th — both missing pairs at once); not needed for the sitting.
