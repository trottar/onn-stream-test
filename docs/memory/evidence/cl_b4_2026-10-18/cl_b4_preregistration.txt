1. The client change (the debug APK only; the seven items of G4-W2 §5.1):
   a. setup: IdentitySession signs sig_v 3 and sends "audio_codecs":["opus"] (canon privyhub-session-setup-v3 =
      v2's seven lines with the v3 name, plus line 8 = the codecs joined by ","). Declared always (under
      identity_v2, as setup is). If the host answers 401 bad-signature to a v3 setup (a host that predates
      sig_v3), one fresh nonce and today's v2 setup, byte for byte (no audio_codecs); logged. Disclosed: this is
      what lets the -r install talk to the running, pre-restart companion.
   b. NativeAudioReceiver accepts PHA1 version 2 (2 ch; frames 240/480/960; payload 1-1500 B), de-duplicated by
      sequence in the same window as today. Version 1 path unchanged.
   c. MediaCodec "audio/opus", 48 kHz, 2 ch, csd-0 = OpusHead (version 1, 2 ch, pre-skip 120, 48000, gain 0,
      family 0), csd-1 = pre-skip in ns (2,500,000) LE64, csd-2 = seek pre-roll in ns (80,000,000) LE64.
      Synchronous, on the receive thread (one producer for the queue, as today). New file OpusAudioDecoder.kt.
   d. Concealment: decode strictly in sequence order. A missing sequence holds later frames until its copy can
      no longer come (a frame with sequence > missing + K arrives, K = max(1, round(offset x 5 / frame_ms)) with
      redundancy on, 0 with it off); then it is abandoned and filled with frames/240 concealment slots — the
      existing concealment (the continuity packet + crossfade). A jump >= 64 sequences: today's cap and crossfade.
   e. The split: each decoded output into 240-frame (960 B) packets for the existing queue; an output that is not
      a multiple of 240 frames (the pre-skip's first) is left-padded with zeros.
   f. Holes per 10 ms: with Opus, lost_packets / sequence_gap_* / recovered_by_duplicate / late_unplaced count Opus
      frames (10 ms each at the default), net of recovery as today. New counters: opus frames decoded,
      abandoned, decode errors, max held, decode time.
   g. The codec in the reports: the end-of-session report's audio block carries "codec" ("pcm" | "opus") and an
      "opus" object; the heartbeat query carries audio_codec=<pcm|opus> (the host ignores unknown keys).
   Unit tests: the pure parts (OpusHead/csd bytes, the reorder/abandon rule, the split/pad, v3 canonical and its
   host vector) as JVM tests; ./gradlew :app:testDebugUnitTest and :app:assembleDebug, offline.
