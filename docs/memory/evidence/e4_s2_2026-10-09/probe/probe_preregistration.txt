  B1 E1-PS1-STREAM at CPUQuota=100% (the default period, 100 ms);

properties and cpu.max / memory.max are read back both ways.

Decision, fixed now: use the DEFAULT period unless B1 stutters and B2 does not. "Stutters" = any of: decoder spikes
>= 20 ms per min >= 200 (session report), rendered fps < 59.5, RetroArch fps < 59.9, the segment-aware capture fps
outside 60 +/- 0.5, encoder dup+drop > 0.2/min. If both stutter or neither does, the default period. Said which.
Membership: RetroArch's and the encoder's /proc/<pid>/cgroup name privyhub-companion.service in both runs
(the runner's cgroup_membership at the window's start and end).
