## 0. Why END ran off (read from the layout and HOME-10)

- The bar is one `LinearLayout` row of fixed widths: 24 / 20 dp padding, the title column (weight 1), the status
  text 280 dp, the preview 184 + 2 × 8 dp, then SAVE / LOAD / END 104 dp and B71's CHANGE DISC 150 dp, each after
  an 8-dp margin.
- **With CHANGE DISC the fixed part is 1018 dp. A 1080p Android TV UI is 1920 px at density 2.0 = 960 dp.** So END
  spans 894-998 dp, and the title column is squeezed to 0.
- The user's "~95 % off" puts the TV's visible right edge at about **899 dp**: about 61 dp (≈ 6 %) of the picture
  is cropped on the right, more than Android TV's 48-dp guideline. (The density is the 1080p TV norm. It fits the
  reading; it was not read on the onn, since there was no adb in this task.)
- The three-button bar is 860 dp fixed; END ends at 940 dp. Nobody has reported it cut, and it is left exactly as it
  is.

## 1. Built (`b73_2026-11-09/b73.diff`, 3 files)

1. **`streaming/PausedBar.kt`** (new, pure):
   - `plan(fit, fourButtons, screenWidthDp)`:
     - three buttons, or the property off → today's / B71's numbers;
     - four buttons with the property on → **SAVE · LOAD · DISC · END at 80 dp with 6-dp gaps, the bar's end padding
       80 dp** (END ends at **880 dp**), and the status text takes what the title's 80-dp minimum leaves: **232 dp at
       960**, clamped 160-280.
   - `layout(plan, width)` places the row as `LinearLayout` does (used by the tests).
2. **"DISC"**: the bar's status text already carries B71's "Disc 2 of 4" under PAUSED, so the button reads DISC with
   the disc line beside it. There is no second row. The chooser and its title are B71's ("Change disc").
3. **`MainActivity`:**
   - `applyPausedBarPlan(four)` runs at the end of `showGameSessionBannerUi`. The first four-button plan captures the
     views' own values (each button's width and margin, the disc label, the status text's width, the bar's end padding
     in px) and then sets the plan;
   - `restorePausedBar()` puts them back whenever the bar is not four buttons: a one-disc banner, media now-playing, or
     the bar hidden. It does nothing if nothing was applied;
   - the start padding, the preview, the heights and the text sizes are untouched.
