===== 4 the companion's own needs (from companion/privyhub_service.py, read 2026-09-23)
paths: COMPANION_DIR = Path(__file__).resolve().parent; PROJECT_ROOT = its parent; logs under PROJECT_ROOT/logs; subprocesses given cwd=PROJECT_ROOT -> independent of the working directory
foreground: main() prints a banner, CONTROLLER.start_server(), ThreadingHTTPServer((CONTROL_HOST, 8765)).serve_forever(); does not daemonise
bind: CONTROL_HOST = "<ipv4>" (all addresses; not a specific address) -> tolerates the wired link coming up after it
stop: only KeyboardInterrupt (SIGINT) is caught; the finally block runs server_close(), shutdown_plugins() (Games reuses its POST stop lifecycle: SAVE_FILES, RetroArch closed), CONTROLLER.shutdown(). No SIGTERM handler: Python's default SIGTERM ends the process at once, the finally block does not run (exit by signal 15, shell status 143) -> an active game is orphaned (TOOLS.md: "Stopping the companion with a game active orphans RetroArch"). With SIGINT it exits 0 after the clean shutdown.
stdout: block-buffered when not a terminal -- the companions stopped by SIGTERM on 2026-09-22 left 0-byte logs (companion_p8_restored, companion_teardown)
