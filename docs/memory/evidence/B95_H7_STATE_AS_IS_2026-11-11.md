# B95 — a state read as it stands, and the proof's statement (2026-11-11)

**Why (Cowork's correction):** the tool runs headless with no pads — a fight is not replayed from a state. What a state
can prove, read as it stands: the "end" state names the player the TV showed, the "begin" state names no winner yet, an
end won by another player names that player, the same on every load. **Baseline:** HEAD `0f881ae5` (HOME-12V
committed). **Design** hashed before code (`b95_2026-11-11/design.sha256`; addendum 1 hashed after it, before the runs).

## Settled first (B94's settle, synthetic fixtures)

A state loaded **while paused** reads exactly — 0 frames pass, every byte as saved, 3 loads equal — on snes9x, Beetle
PSX HW and Mupen64Plus-Next. RetroArch 1.22.2 logs `[State] Loading state "…", N bytes.` (N > 0 when the file was read)
and, on a failure, `Failed to load state from "…"`: a corrupt file reads 0 bytes then fails; a well-formed container the
core refuses reads N > 0 bytes then fails. **B93's check accepted any `[State]` line with "oad" and the file's name —
the failure line included.**

## Built (`tools/h7_minigame_proof.py`)

- **`--as-is`** (also `--seconds 0`): pause, then load paused, read, quit — **0 frames run** (on the fixture every value
  read back exactly as written, and the program advances them every frame). `--seconds N` keeps B93's run.
- **The load check:** the `Loading state … N bytes` line with N > 0 and no failure line within 1 s; else an error.
- **`"none_when": "equal"`** (or `{"floor": V}`) → `"winner": null`, `"reason": "no winner yet"` (a rule without it answers
  `"tie"` as B93's); **B94's single-field rule** (`address`, `values` per winner, `none_value`) → that player / no winner
  yet / `"unknown"`.
- **`--runs N`**: N fresh RetroArch loads; one JSON line with `"agreement": "k of N"`, every run's winner and values; the
  winner only when k = N, else `"winner": "disagree"`.
- **`--make-state`** writes and saves **paused** (the state holds exactly what was written).
- **The game read in place** (addendum 1): B93 copied it into the temp folder — for a PS1 disc image a large copy on
  every load, and a `.cue` would lose its tracks. RetroArch only reads content.
- **A paused RetroArch does not act on QUIT** (B93's close waited 5 s, then killed it): now QUIT, 1 s, SIGTERM, 3 s,
  SIGKILL.
- **The proof's statement**, in the help and ROADMAP §H7 (an insertion; the old line kept, marked superseded): "Met on a
  real game when, read as they stand, the 'end' state names the player the TV showed, the 'begin' state names no winner,
  and — where the user has made one — an 'end' state won by another player names that player; the same on 3 loads each.
  The fixed run with real players is tested later, on the stream."
