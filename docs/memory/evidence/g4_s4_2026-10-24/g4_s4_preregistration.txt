1. The driver: g4_s4_driver.py as the systemd --user transient unit privyhub-g4-s4; status ~/privyhub_g4_s4/status.txt;
   STOP = touch ~/privyhub_g4_s4/STOP; RUNS NO SUITE.
   - Idle wait: before writing the drop-in, the driver waits until no game is active and no connection is open on
     the range server's port, read twice 15 s apart (the restart would end either). The wait ends at STOP or the cap.
     A choice, disclosed: the task's precondition is "no game"; waiting is the same rule as G4-S3's "the launch did
     not go over it".
   - e3_flag.conf = exactly PRIVYHUB_REMOTE_LADDER=1, PRIVYHUB_START_RUNG=floor, PRIVYHUB_REMOTE_RUNG_CAP=7000,
     PRIVYHUB_WAN_TELEMETRY=1. The environ reads back FOURTEEN lines (10 + 4), else the drop-in is removed at once and
     the driver exits (nothing played under it).
   - Samplers: every 10 s the tailnet interface's tx/rx bytes (the interface name not written) + the native stream's
     status (active, bitrate, ladder level/state, the encoder's -b:v); every 60 s the overlay state (connected, path,
     peer_ready, mtu, reason; RTT if offered) and the WAN telemetry block (scrubbed); every 60 s the session state
     (game active / paused, the system class only, elapsed; the native stream active; VOD = the count of established
     connections on the range server's port, a count only); every 5 min the rotating logs (logs/games/*: the ladder
     log, heartbeat, recovery, ctrl gaps, frame sizes, host samples, pulseaudio, video log; the archive's .1 read when
     a log rotated under it; new decoder_sessions/ and audio_timing/ files) and the companion's journal copied into
     ~/privyhub_g4_s4/ (outside the repo: raw logs may carry endpoints; Part 2 writes only redacted readings).
   - The cap: the driver's start + 2 h 30 min (9000 s), the absolute time written at the start to cap_utc.txt and the
     status line. On STOP or the cap: a last copy, the drop-in removed, restart, flags_absent read, the ten lines
     read, a copy after the restart. The restart at the end ends any running stream: the user says "stop" only when
     done.

   applies: the tailnet rate and the data only):

     relayed) and its changes; post-/pre-FEC loss; rendered, stale, resyncs, pauses;
   - THE STACK'S ROWS: every input_hold / state_saved / input_release / stall pause, each tagged a REAL DROP (the
     control gap >= 3 s or a dark span) or a FALSE HOLD (the link alive on both sides), the count per 10 min, and

     uplink silence that is not a drop fires a false hold: COUNTED;

     (>= 20 / >= 50 ms per min), state loads, the data per hour (MB/h on the tailnet interface).
   - Comparisons: G4-S1 run 1 (7000, PCM, the tailnet), G4-S3 (4000, Opus, hotspot), the 5-GHz LAN (CL-B12).
