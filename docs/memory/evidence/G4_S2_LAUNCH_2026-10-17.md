**Each run:**
1. `e3_flag.conf` is written, then daemon-reload and a restart.
2. The environ is read back. **It must be eleven lines** (the seven adopted plus the run's four), or the run is not
   started.
3. `python3 tools/e1_suite.py run --remote --out …/g4_s2_2026-10-17/runs/run<N>_<arm> --prereg
   …/g4_s2_preregistration.txt --runs 1 --window 600 --gap 300 --wait 900` runs, **with no `--adb`**.
4. Then, always:
   - the drop-in is removed (`e1_suite.teardown_flags`);
   - daemon-reload and a restart;
   - `flags_absent` is read.

**What ends a run early or ends the driver:**
- A LAN-class run is void and is replaced once.
- A refusal, or a teardown that is not `flags_absent`, ends the driver.
- The STOP file `~/privyhub_g4_s2/STOP`.
- The cap: no run starts at or after 19:55Z.

**The launch:**
